Машинное обучение

Программа не следует жёстким правилам, а «учится» на примерах: например, предсказывает категорию обращения клиента по его тексту. Понадобится чуть больше кода и терпения.

Мифы и страхи новичка — честно

Большинство сомнений знакомы каждому, кто начинал. Давайте разберём их без рекламных обещаний.

Нужна сильная математика

Частично правда. Для учебных проектов достаточно школьной базы: процентов, средних значений и логики. Глубокая математика понадобится позже — и её можно подтягивать постепенно, по мере необходимости.

Это только для тех, кто с детства программирует

Нет. Многие приходят в анализ данных из гуманитарных и естественных специальностей: знание своей предметной области — это даже плюс, ведь именно вы понимаете, какие вопросы стоит задавать данным.

Нужен мощный компьютер и платные сервисы

Для старта — нет. Все проекты на этой странице выполняются на обычном ноутбуке с бесплатными инструментами и открытыми данными. Платный доступ нигде не требуется.

Я не потяну, брошу на середине

Риск реальный — и его можно снизить. Главный секрет — выбрать маленький проект с видимым результатом за 2–4 недели и заниматься понемногу, но регулярно. Именно для этого ниже есть подборка проектов и мини-тест.

Три первых проекта — выберите свой

Лёгкий старт 📈

Анализ открытого датасета

Берёте бесплатный набор данных на интересную вам тему (спорт, кино, погода, учёба), очищаете его и строите 5–7 графиков с выводами.

  • Ориентировочно 2–4 недели по 3–5 часов в неделю
  • Навыки: основы Python, работа с таблицами, графики
  • Результат: наглядный отчёт, который не стыдно показать

Средний уровень 💬

Чат-бот на готовой модели

Создаёте бота, который отвечает на вопросы по выбранной теме — например, помогает первокурсникам разобраться в расписании. Используется готовая бесплатная языковая модель, платный API не нужен.

  • Ориентировочно 3–6 недель по 3–5 часов в неделю
  • Навыки: основы Python, работа с готовыми библиотеками
  • Результат: работающий бот, которым можно пользоваться

Распознавание изображений

Обучаете программу отличать, скажем, фотографии птиц от фотографий самолётов. Нейросеть не строится с нуля — берётся готовая бесплатная модель и дообучается на ваших примерах.

  • Ориентировочно 4–8 недель по 4–6 часов в неделю
  • Навыки: уверенные основы Python, терпение к экспериментам
  • Результат: модель, распознающая ваши собственные фото
